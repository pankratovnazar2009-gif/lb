# ФК «Лівий Берег» — сайт

Сучасний редизайн офіційного сайту футбольного клубу «Лівий Берег» (Київ).
Next.js 16 · React 19 · TypeScript · Tailwind v4 · Lenis · Motion.

## Розробка

```bash
npm install
npm run dev      # http://localhost:3000  →  редірект на /uk
```

- `npm run build` — прод-збірка (запускає перевірку типів)
- `npm start` — прод-сервер
- `npm run lint` / `npm run typecheck`

`?flat` у URL (`/uk?flat`) заморожує анімації — для QA і скріншотів.

## Мови

`uk` (типова) та `en`. Перемикач у хедері. Весь UI-текст — у `src/i18n/dictionaries/`.

## Контент

Увесь контент (склад, тренери, новини, матчі, таблиця, історія, контакти) — у
`src/content/*.ts`. Це знімок із [fclb.com.ua](https://fclb.com.ua/) станом на вересень 2026.
Щоб оновити — редагуйте відповідний файл; збірка статична, CMS немає.

Фото гравців і тренерів — у `public/players` та `public/coaches` (стиснуті студійні
портрети; білий фон виноситься на полотно через `mix-blend-mode: darken`).
